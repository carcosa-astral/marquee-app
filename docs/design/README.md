# Marquee design

Mocks of every screen in the Nord theme. They were made as clickable-looking design boards, so the data is sample data and the posters are gradient placeholders.

- `mocks/` holds one `.dc.html` file per screen. They are readable source files that show the exact layout, spacing, colors and copy. Open them in a text editor to read the values. They are references for building the Avalonia views, not part of the app.
- All names of theaters in the mocks are invented. The real app ships with no theaters.
- Colors, fonts and status colors are listed in `docs/BUILD_PLAN.md`, section 9.

When a mock and the build plan disagree, ask the owner.
